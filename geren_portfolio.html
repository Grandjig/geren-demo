The Challenge

African Markets Are Ignored

Global quantitative systems don't model African markets. Classical optimization methods fail because they assume stable currencies and predictable policy environments.

The Problem

  • No coverage from global quant funds
  • Classical methods miss naira cycles, CBN policy, election risk
  • 20% currency devaluation destroys returns
  • Generic models trained on NYSE, not NGX
  • No self-improvement — set once, degrade forever

GEREN's Solution

  • Built for African market dynamics
  • Nigerian macro signals: oil, currency, politics
  • Natural hedges protect against naira weakness
  • Self-improving: gets better with every cycle
  • Full audit trail for every decision

Architecture

How GEREN Works

A self-improving optimization engine that combines multiple signal sources, tests hypotheses, and learns from every execution.

1

Signal Intelligence

Combine price momentum models, technical indicators (RSI, MACD), and Nigerian macro context (oil, currency, CBN policy, elections).

2

Asset Selection

Rank assets by signal-augmented Sharpe ratio. Select top performers for the portfolio.

3

Weight Optimization

Use Hierarchical Risk Parity (HRP) for robust weight allocation. No mean-variance assumptions.

4

Self-Improvement

AI proposes parameter changes → system tests them → keeps improvements, rejects regressions, logs everything.
